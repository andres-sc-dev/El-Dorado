# El Dorado — datos de desarrollo

**Apuestas del Fútbol Colombiano · Vuelve la época dorada**

Toda esta carpeta `src/data/` es una simulación temporal de base de datos para desarrollo del frontend. Los archivos de esta carpeta representan tablas de negocio como `users`, `matches`, `odds`, `bets`, `promotions` y demás, con datos semilla para probar la interfaz visual y la navegación. Esta capa debe eliminarse por completo cuando se conecte el backend real, y su uso dentro de `src/services/` debe reemplazarse por llamadas HTTP reales a la API.
